    System

    The scheduled tasks behind the jobs, exactly as your account has them, read live.

    How it is set up

    Business Santa jobs run inside four daily runs (morning, afternoon, evening, night) and one hourly run, so they take turns on one Chrome. Each job's full instruction is kept in its original scheduled task, which is switched off on purpose; the run reads it and carries it out step by step. Each run records which steps finished, so a retry redoes only what failed. Manu Vishranti jobs each run on their own. Two catch-ups check every hour, day and night, and run anything missed while the laptop was off. The supervisor checks everything every hour, retries, fixes what it can and tells you what needs you.
